# jenkins2: Jenkins as code

[![ci](https://github.com/shivanjalikaname/jenkins2/actions/workflows/ci.yml/badge.svg)](https://github.com/shivanjalikaname/jenkins2/actions/workflows/ci.yml)

A Jenkins controller where **nothing is configured by clicking**. Plugins, security, the shared library and the jobs all live in this repo. Rebuilding the server is `docker compose up`, and every change goes through review like any other code.

> This repo began in 2017 as a Chef cookbook that installed Jenkins. It's been rebuilt the way I run Jenkins today: a container image plus Configuration as Code.

## What's inside

| Path | Purpose |
|------|---------|
| [Dockerfile](Dockerfile) | Jenkins LTS (JDK 21) with plugins baked in at build time, setup wizard off |
| [plugins.txt](plugins.txt) | The plugin list, installed with `jenkins-plugin-cli` |
| [casc/jenkins.yaml](casc/jenkins.yaml) | JCasC: security realm, permission matrix, CSRF, shared library, generated jobs |
| [vars/standardPipeline.groovy](vars/standardPipeline.groovy) | Shared pipeline: build, test, deploy gate, timeouts, log retention, workspace cleanup |
| [vars/withRetry.groovy](vars/withRetry.groovy) | Retry with exponential backoff for flaky steps |
| [examples/Jenkinsfile](examples/Jenkinsfile) | A service pipeline in 5 lines |
| [scripts/smoke-test.sh](scripts/smoke-test.sh) | Proves the controller booted with the expected security and jobs |

## Security choices

- **No secrets in git:** the admin password is generated by `scripts/init-secrets.sh` into a git-ignored directory and mounted as a Docker secret. JCasC reads it from `/run/secrets`.
- **No anonymous access:** signup is disabled, logged-in users get read-only access and only the admin can configure.
- **No builds on the controller:** `numExecutors: 0`, so builds run on agents and can't touch `JENKINS_HOME`.
- **Job DSL runs under script security,** and the CSRF crumb issuer is on.
- **Port bound to 127.0.0.1:** put a TLS reverse proxy in front for real use.

## Run it

```bash
./scripts/init-secrets.sh
docker compose up -d --build
./scripts/smoke-test.sh
```

Open http://localhost:8080 and log in as `admin` with the password in `secrets/jenkins_admin_password`.

## Using the shared library

```groovy
@Library('pipeline-lib') _

standardPipeline(
    buildCmd: 'make build',
    testCmd: 'make test',
    testReports: 'build/test-results/**/*.xml',
    deployCmd: './deploy.sh production',   // runs only on the main branch
)
```

Every service then gets the same 30-minute timeout, timestamps, build retention, abort-previous-build behaviour and workspace cleanup, so fixing one of them fixes it everywhere.

## CI

- **Lint:** hadolint, shellcheck, yamllint, and a Groovy compile of the shared library.
- **Boot test:** builds the image, starts Jenkins and runs the smoke test (anonymous access denied, admin login works, Job DSL created the jobs, controller has no executors).

CI also runs weekly, so a plugin update that breaks the configuration shows up before the next real rebuild.
